This is a game I wrote way back in 2004 in Processing. The original was written in Java and this is a straight
port of the code into JavaScript and moved over from [Processing](https://processing.org/) to [P5JS](https://p5js.org/).

The game itself is a variation of the cave flyer game genre that started in 1995 with [SFCave](https://www.mobygames.com/game/48137/sfcave/)
and includes the famous [Flappy Bird](https://en.wikipedia.org/wiki/Flappy_Bird) variant.

To play the game, click or hold the mouse button to boost your ship upwards and let it go to let it fall. The game is over if you
touch the floor, ceiling, or one of the bars. Keep going for as long as you can to earn a high score.

You can collect bonus points by taking risks. Hover close to the floor or ceiling to earn a "sparks flying" bonus. Pass through
a yellow barrier for a "cutting it fine" bonus. Get a "sneaky bugger" bonus by making it through a red barrier.

There are a couple of key controls available too:

 - **P** Pause the game
 - **S** Toggle antialiasing
 - **D** Debug mode
 - Any other key can be used to boost the ship if you prefer key controls over the mouse
